FAQ

Questions, answered

Where does Typewave work?

In almost every text box in Chrome: Gmail, Outlook on the web, LinkedIn, Slack, Zendesk, Intercom, HubSpot, Salesforce, Notion, WhatsApp Web, and ordinary web forms. Google Docs draws its own text, so there you use the picker to copy a snippet and paste it. Typewave never runs in password fields.

Do I need an account?

No. Typewave works the moment you install it. You only sign in with Google if you buy Pro, so your plan follows you to every computer.

Is the AI really private? Does it cost extra?

Typewave uses Gemini Nano, the AI model built into Chrome. It runs on your computer, so the text you write stays there, and there's no per-message cost. It needs Chrome 138 or newer on a desktop with enough memory; Typewave tells you if yours can't run it.

What happens if I stop paying?

Nothing renews automatically. When your Pro time ends, Typewave switches to Free and keeps every snippet. Fill-in fields then insert their default text until you upgrade again.

Can I bring snippets from another text expander?

Yes. Export from your current tool as JSON and import it under Settings → Backup. Typewave understands the common formats (shortcut / abbreviation plus text / content).

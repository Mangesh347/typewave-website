Getting started

  1. Install Typewave from the Chrome Web Store. It adds six starter snippets like /ty and /sig.
  2. Click in any text box and type /ty. It becomes the full text right away.
  3. Click the Typewave toolbar button → New snippet to write your own.

A shortcut didn't expand

  • Reload tabs that were open before you installed Typewave; Chrome only adds it to pages loaded afterwards.
  • Check that the site isn't paused: click the Typewave button and look at the switch for this site.
  • Google Docs, Sheets, and some code editors draw their own text, so expansion can't work there. Press Ctrl+Shift+Space to copy a snippet and paste it.
  • Chrome pages (chrome://…) and the Chrome Web Store block all extensions.

Two shortcuts clash

If /ty fires while you're typing /typo, open Settings → General → "When to expand" and choose After I press Space. Then each shortcut expands only when you finish it with a space.

AI Writer says it isn't available

Typewave's AI uses the model built into Chrome. It needs Chrome 138 or newer on Windows 10/11, macOS 13+, or Linux, about 22 GB of free disk space, and either a GPU with more than 4 GB of memory or 16 GB of RAM. Chromebooks and phones aren't supported yet.

Pro isn't showing after I paid

  1. Open Typewave → Settings → Account and click I already paid / Check again.
  2. Make sure you signed in with the same Google account you paid with.
  3. Still stuck? Email us your PayPal or Razorpay payment ID and we'll fix it the same day.

Moving to a new computer

With Pro, turn on Settings → Sync on both computers. On Free, use Settings → Backup → Export and import the file on the new computer.
